# חיבור Google Sheets למערכת עסקית

החיבור משתמש ב-Google Apps Script וב-Google Sheets. אין צורך ב-n8n או Make או בשירות מנוי נוסף. חשבון Google רגיל מספיק, בכפוף למכסות השימוש החינמיות של Google.

## 1. יצירת גיליון
1. היכנסו ל-Google Sheets וצרו גיליון חדש בשם **פניות – שם העסק**.
2. העתיקו את מזהה הגיליון מהכתובת: הערך שבין `/d/` לבין `/edit`.
3. אין צורך ליצור כותרות או עמודות; הסקריפט ייצור אותן אוטומטית בלשונית **פניות**.

## 2. יצירת Web App
1. בגיליון פתחו **Extensions → Apps Script**.
2. החליפו את תוכן `Code.gs` בתוכן הקובץ שבמאגר.
3. ב-**Project Settings → Script Properties** הוסיפו:
   - `SPREADSHEET_ID` – מזהה הגיליון.
   - `WEBHOOK_SECRET` – מחרוזת אקראית חזקה. אין לשלוח אותה בצ'אט או להכניס אותה לקוד.
4. ב-Windows PowerShell ניתן ליצור סוד:
   ```powershell
   $bytes = New-Object byte[] 32
   [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
   [BitConverter]::ToString($bytes).Replace("-", "")
   ```
5. לחצו **Deploy → New deployment → Web app**.
6. בחרו **Execute as: Me** ובגישה **Anyone**. הגישה הציבורית נדרשת כדי שהאתר יוכל לשלוח פניות ללא התחברות Google; כל בקשה נבדקת מול הסוד המשותף לפני כתיבה לגיליון.
7. העתיקו את כתובת ה-Web app שמסתיימת ב-`/exec`.

## 3. הגדרת סביבת האפליקציה
בשירות האירוח של הלקוח הוסיפו:
- `LEAD_WEBHOOK_URL` – כתובת ה-Web app.
- `LEAD_WEBHOOK_SECRET` – בדיוק אותו סוד שהוגדר ב-Script Properties.

שמרו ובצעו Deploy אם סביבת האירוח אינה מתחילה פריסה אוטומטית.

## 4. בדיקה
1. בצעו בדיקה רק עם נתוני בדיקה מוסכמים ובסביבת הלקוח המתאימה.
2. ודאו שהפנייה מופיעה בלשונית **פניות** עם מספר הפנייה, תאריך ופרטים.
3. שליחה חוזרת של אותו מזהה פנייה לא תיצור שורה כפולה.
4. אם Apps Script אינו זמין או שהסוד שגוי, הפנייה עדיין נשמרת במסד הנתונים של האתר; הכשל נרשם בלוגים.

## פרטיות ואבטחה
- אין לשמור את הסוד בקובץ הקוד או ב-GitHub.
- הסוד נשמר רק ב-Script Properties ובסביבת האירוח.
- הגבילו את שיתוף הגיליון למורשים בלבד.
- הסקריפט מגן מפני נוסחאות שמוזנות כטקסט חופשי ומונע שורות כפולות לפי מספר הפנייה.
- Google Apps Script ו-Sheets כפופים למכסות חינמיות שעשויות להשתנות.

## ביטול החיבור
כדי להפסיק העברת פניות לגיליון, הסירו את `LEAD_WEBHOOK_URL` מסביבת האפליקציה. הפניות ימשיכו להישמר באתר כרגיל.
