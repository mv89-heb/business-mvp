# חיבור חינמי ל-Google Sheets

החיבור משתמש ב-Google Apps Script וב-Google Sheets. אין צורך ב-n8n או Make, ואין שירות מנוי נוסף. חשבון Google רגיל מספיק בכפוף למכסות השימוש החינמיות של Google.

## 1. יצירת הגיליון
1. היכנסו ל-Google Sheets וצרו גיליון חדש בשם **פניות – אלי כהן בניה ועץ**.
2. העתיקו את מזהה הגיליון מהכתובת: הערך שבין `/d/` לבין `/edit`.
3. אין צורך ליצור כותרות או עמודות; הסקריפט ייצור אותן אוטומטית בלשונית בשם **פניות**.

## 2. יצירת Web App
1. בגיליון פתחו **Extensions → Apps Script**.
2. החליפו את תוכן הקובץ `Code.gs` בתוכן הקובץ הזה מתוך המאגר.
3. ב-**Project Settings → Script Properties** הוסיפו:
   - `SPREADSHEET_ID` – מזהה הגיליון שהעתקתם.
   - `WEBHOOK_SECRET` – מחרוזת אקראית חזקה שתייצרו אצלכם. אין לשלוח אותה בצ'אט או להכניס אותה לקוד.
4. צרו סוד ב-PowerShell במחשב Windows:
   ```powershell
   $bytes = New-Object byte[] 32
   [Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($bytes)
   [BitConverter]::ToString($bytes).Replace("-", "")
   ```
   העתיקו את התוצאה לשדה `WEBHOOK_SECRET` ב-Script Properties. שמרו אותה באופן זמני כדי להגדיר את אותו הערך גם ב-Render.
5. לחצו **Deploy → New deployment → Web app**.
6. בחרו **Execute as: Me** ובגישה **Anyone**. הגישה הציבורית נדרשת כדי שהאתר יוכל לשלוח פניות ללא התחברות Google; כל בקשה נבדקת מול הסוד המשותף לפני כתיבה לגיליון.
7. אשרו את ההרשאות והעתיקו את כתובת ה-Web app שמסתיימת ב-`/exec`.

## 3. הגדרת Render
ב-Render פתחו את השירות `eli-cohen-business-mvp-iqem` → **Environment** והוסיפו:
- `LEAD_WEBHOOK_URL` – כתובת ה-Web app המסתיימת ב-`/exec`.
- `LEAD_WEBHOOK_SECRET` – בדיוק אותו סוד שהגדרתם ב-Script Properties.

שמרו ובצעו Deploy אם Render לא מתחיל פריסה אוטומטית.

## 4. בדיקה
1. שלחו פנייה אמיתית לבדיקת המערכת רק לאחר תיאום, או השתמשו בנתוני בדיקה מוסכמים.
2. ודאו שהפנייה מופיעה בלשונית **פניות** עם מספר הפנייה, תאריך ופרטי הפרויקט.
3. שליחה חוזרת של אותו מזהה פנייה לא תיצור שורה כפולה.
4. אם Apps Script אינו זמין או שהסוד שגוי, הפנייה עדיין נשמרת במסד הנתונים של האתר; הכשל נרשם בלוגים של Render.

## פרטיות ואבטחה
- אין לשמור את הסוד בקובץ הקוד או ב-GitHub.
- הסוד נשמר רק ב-Script Properties וב-Render Environment.
- אל תשתפו את כתובת ה-Web app יחד עם הסוד.
- הגיליון מכיל פרטי קשר של לקוחות; הגבילו את שיתוף הגיליון למורשים בלבד.
- הסקריפט מגן מפני נוסחאות שמוזנות כטקסט חופשי ומונע שורות כפולות לפי מספר הפנייה.
- Google Apps Script ו-Sheets כפופים למכסות החינמיות של Google שעשויות להשתנות. אין התחייבות לשירות ללא הגבלה.

## ביטול החיבור
כדי להפסיק העברת פניות לגיליון, הסירו את `LEAD_WEBHOOK_URL` מ-Render Environment. הפניות ימשיכו להישמר באתר כרגיל.
